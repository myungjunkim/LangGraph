UI 변경 비교 — 현재 vs 제안

왼쪽은 현재 화면(resources/static/index.html 의 CSS 를 그대로 사용), 오른쪽은 제안 3건만 덧씌운 화면입니다. 내용은 양쪽이 동일합니다.

현재 index.html 그대로

제안 변경 1·2·3 적용

무엇이 달라졌나

  1. 답변 아바타 → 왼쪽 괘선: 파란 원 A 배지를 없애고 border-left 세로선으로 턴을 구분합니다.
  2. 질문 말풍선 → 문서 제목: 파란 말풍선 대신 좌측 정렬 굵은 제목 + 아래 border-bottom 구분선으로 보여 줍니다.
  3. 예시 질문 2×2 → 한 줄 pill: 카드 그리드를 라벨+문구가 한 줄에 들어가는 둥근 pill 가로 행으로 바꿉니다.

CSS 만 바뀝니다. DOM 구조·JS 로직·서버·SSE 계약은 그대로입니다.
