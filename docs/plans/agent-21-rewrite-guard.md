## 목표

`rewrite` 노드가 만든 "독립 질문" 이 정상적인 한 문장일 때만 사용하고, 그렇지 않으면 **사용자 원문 질문으로 안전하게 되돌린다.**

## 문제 (agent-19 D1, `[검증]`)

`src/agent.py:139` 가 LLM 출력을 **검증 없이** 그대로 쓴다.

```python
return {"standalone_question": response.content.strip(), "forced": False}
```

실제 사용자 스레드(`c36b3085-…`)에서 `standalone_question` 에 **직전 답변 전문(API 9개 목록 + 마크다운 출처 링크)** 이 들어갔다.
"넌 안되겠다", "자꾸 틀린 답을하네" 처럼 **독립 질문으로 리라이팅할 수 없는 입력**이 오면 모델이 앞 답변을 복사해 뱉는다.

### 피해가 두 갈래다

1. **검색어 오염** — `force_search`(`src/agent.py:157`)와 모델의 후속 `search_*` `query` 인자에 수천 자가 들어간다. 검색 품질이 무너진다.
2. **질문 자체가 바뀐다 (더 심각)** — `replace_last_question`(`src/agent.py:146`)이 **모델에게 넘기는 마지막 HumanMessage 를 통째로 치환**한다. 사용자는 "넌 안되겠다" 라고 했는데 모델은 "API 9개 목록…" 을 질문으로 받는다. **사용자가 하지 않은 질문에 답하는 상태**가 된다.

### 왜 안 보였나

예외가 없고, 화면·DB·CLI 에는 **사용자 원문이 그대로 남는다**(의도된 설계, `agent.py:145-146` 주석). 그래서 로그로도 안 보이고 체크포인트 내부를 열어야 드러난다.
**두 번째 턴 이후 모든 대화**에 걸리며, 앞 답변이 쌓일수록 발동 확률이 올라간다(길수록 복사할 것이 많다).

## 설계

### 핵심: 폴백에 새 코드가 필요 없다

`standalone_question` 이 **빈 문자열이면 원문을 쓰는 경로가 이미 있다.**

- `replace_last_question`(`agent.py:51-52`): 비어 있으면 `list(messages)` 를 그대로 반환.
- `force_search`(`agent.py:157`): `state.get("standalone_question") or last_user_question(messages)`.

→ **거부 = 빈 문자열 반환.** 그러면 첫 턴과 똑같은 정상 경로를 탄다. 새 분기·새 상태 필드를 만들지 않는다.

### T0. 먼저 실측한다 (구현 전 필수)

임계값을 감으로 정하지 않는다. `data/checkpoints.sqlite` 를 **읽기 전용(`mode=ro`)** 으로 열어 기존 17개 스레드의 **실제 `standalone_question` 값을 전수 조사**하고 다음을 보고해라.

- 값의 개수, 길이 분포(최소/중앙/최대), 개행 포함 건수
- **정상 리라이팅으로 보이는 것**과 **오염된 것**을 눈으로 분류한 목록(각각 몇 건인지, 대표 사례 원문)
- 아래 임계값이 그 실데이터에서 **정상을 하나도 거부하지 않는지**

**`MAX_CHARS=200` 이 실데이터와 맞지 않으면 구현하지 말고 ESCALATE 해라.** 이 값은 리드가 실측 없이 제시한 초기값이다.

### T1. 검사 함수

`src/agent.py` 에 **순수 함수**로 추가한다(테스트 용이성). 이름은 기존 컨벤션(`replace_last_question`, `turn_has_tool_results`)에 맞춰 서술형으로.

```python
MAX_STANDALONE_QUESTION_CHARS = 200   # 모듈 상수. T0 실측으로 확정

def sanitize_standalone_question(text: str) -> str:
    """리라이팅 결과가 정상적인 한 문장일 때만 돌려준다. 아니면 빈 문자열(→ 원문 사용)."""
```

**거부 조건** (하나라도 걸리면 `""`):

| # | 조건 | 이유 |
|---|---|---|
| 1 | `strip()` 후 비어 있음 | 기존 동작과 동일 |
| 2 | 길이 > `MAX_STANDALONE_QUESTION_CHARS` | 질문이 아니라 본문이다 |
| 3 | 개행(`\n`) 포함 | `REWRITE_PROMPT` 가 "한 문장만 출력" 을 요구한다. 답변 전문은 반드시 여러 줄이라 **이 조건 하나가 실제 사고를 잡는다** |
| 4 | 마크다운 링크 `](http` 또는 `](/` 포함 | 출처 링크가 섞였다 |
| 5 | 굵게 표시 `**` 포함 | 답변 서식이다 |

- 판정은 `strip()` **후** 값으로 한다. 통과하면 그 `strip()` 된 값을 반환한다.
- **목록 기호(`- `, `1. `)는 검사하지 않는다** — 정상 질문에 하이픈·숫자가 들어갈 수 있고(`"v2/v3 - 차이"`), 실제 답변 복사는 조건 2·3 에 먼저 걸린다. **거짓 양성을 만들면서까지 중복 방어하지 않는다.**

### T2. 적용

`rewrite` 노드(`agent.py:139`)에서 이 함수를 통과시킨다. 그 외 노드·상태·프롬프트는 건드리지 않는다.
