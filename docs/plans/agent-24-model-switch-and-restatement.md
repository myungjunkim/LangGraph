## Part B — 진술형 오염 실측 (A1 통과 시에만)

### 문제

`[검증]` agent-23 실측: 새 모델에서 **주된 오염 형태가 "진술형"** 이다 — 가드를 통과한다.

```
'주제 정보 검색 API 의 필수 파라미터는 `company_seq`, `user_id` 입니다.'   (53자/1줄, 마크다운 없음)
```

질문이 아니라 **진술**이 `standalone_question` 이 되어, 검색어와 **모델이 받는 질문 자리**에 들어간다(`replace_last_question`).
agent-21 판단 (8)이 예고한 잔여 위험이고, agent-23 에서 **프롬프트로는 해결되지 않음이 확인됐다**(후보 7종 전부 실패, P2 는 악화).

### 남은 접근: 직전 AI 답변과의 대조

형식이 아니라 **출처**를 본다. 리라이팅 결과가 **직전 답변을 베낀 것**이면 거부한다.

### B1. 실태 측정
- 기존 DB(`-wal`·`-shm` 포함 사본, `mode=ro`)의 `standalone_question` 고유값 + **새 모델로 생성한 값**을 합쳐 모집단을 만든다.
- 각 값을 분류: **정상 질문 / 진술형 오염(가드 통과) / 형식 오염(가드가 이미 거부)**. 건수와 대표 사례 **원문**.
- 새 모델에서 진술형이 실제로 몇 %인지가 이 티켓의 존재 근거다.

### B2. 후보 규칙 평가

| # | 규칙 |
|---|---|
| D1 | rewrite 결과 **전체**가 직전 AI 답변의 부분 문자열인가 |
| D2 | 정규화(공백·구두점·마크다운 제거) 후 부분 문자열인가 |
| D3 | 문자 N-gram 중복률이 임계 이상인가(임계값을 **탐색해 보고**) |
| D4 | D1~D3 중 하나 + "물음표로 끝나지 않음" 조합 |

- **각 규칙의 거짓 양성/음성을 B1 모집단 기준 숫자로** 보고해라.
- **거짓 양성이 최우선 기준이다.** 정상 리라이팅을 거부하면 문맥 보정이 죽는다(agent-21 W1 과 같은 위험).
- **주의**: 정상 리라이팅도 직전 답변의 **단어**(API 이름 등)를 포함한다. 그래서 **부분 일치 기준을 어떻게 잡느냐**가 전부다. 임계값을 감으로 정하지 말고 **데이터에서 찾아라.**
- 규칙을 추가해도 된다. 추가했다면 가설과 함께 보고.

### B3. 가치 판단
- 진술형 빈도가 낮거나, 거짓 양성 0 인 규칙이 없으면 **기각이 정당한 결론이다**(agent-22·23 선례).
- **억지로 규칙을 만들지 마라.**

#### 진술형이 실제로 해를 끼쳤는가

관측된 실제 영향은 둘이다.

1. `[검증]` **답변이 `"네, 맞습니다."` 로 시작한다**(N 2턴, RN 3턴). 질문에 답한 게 아니라 **단언에 동의하는** 말투다.
2. `[검증]` **모델이 도구를 부르지 않게 된다.** 진술형이 된 7턴 중 5턴에서 모델이 도구를 생략해 `force_search` 가 대행했다
   (진술에는 검색할 질문이 없으니 자연스러운 귀결이다). 강제 검색이 받아 주므로 답변은 살아남지만, **검색어가 진술문이 된다.**

`[추측]` 사례 (5)처럼 **지어낸 진술**이 질문 자리에 들어가면 모델이 그 전제를 승인할 위험이 있다. 이번 세트에서는 재현되지 않았다.

### B2. 후보 규칙 평가

정규화는 공백·마크다운 기호·구두점을 전부 지우고 한글/영숫자만 남긴다. 점수 계산 `a24/b2_rules.py`, 평가 `a24/b2_eval.py`.
**평가 대상은 현행 가드를 통과한 90건**(형식 오염 6건은 이미 걸러지므로 제외).
**거짓 양성 = 정상(34건)을 거부 / 탐지 = 진술형(47건)을 거부.**

| # | 규칙 | 거짓 양성 | 탐지 | 거짓 음성 |
|---|---|---|---|---|
| **D1** | 원문 그대로 직전 답변의 부분 문자열 | **0 / 34** | **2 / 47** | 45 / 47 |
| **D2** | 정규화 후 부분 문자열 | **0 / 34** | **3 / 47** | 44 / 47 |
| **D4** | (D1 또는 D2) + 물음표로 끝나지 않음 | **0 / 34** | **2 / 47** | 45 / 47 |

- `[검증]` **D1·D2·D4 는 거짓 양성이 0 이지만 거의 아무것도 못 잡는다.**
  잡힌 2~3건은 전부 **기존 DB(옛 모델)의 날짜 스레드**다. **새 모델만 보면 탐지 0/30 이다.**
- `[검증]` 이유는 분명하다. 새 모델의 진술형은 **복사가 아니라 바꿔 쓴 요약**이다.
  예: 답변은 표(`| \`service_key\` | string | 서비스 키 |`)인데 리라이팅은 쉼표 나열 한 문장이다. 부분 문자열이 될 수 없다.

#### D3 / D5 — 임계값을 **데이터에서** 찾았다 (Z5)

임계값을 먼저 정하지 않고, **정상군 점수의 최댓값**을 구해 "거짓 양성 0 을 만족하는 최소 임계값" 을 데이터가 정하게 했다.
0.00~1.00 을 0.05 간격으로 전수 스윕한 표는 `a24/b2_eval.py` 출력에 전부 있다.

| 점수 | 정상군 최대 | 진술형 중앙 | 거짓 양성 0 을 만족하는 임계 | 그때 탐지(전체) | **그때 탐지(새 모델만)** |
|---|---|---|---|---|---|
| D3 문자 3-gram 포함률 | 0.64 | 0.44 | > 0.64 | 13 / 47 | **8 / 30** |
| D3 문자 4-gram 포함률 | 0.58 | 0.38 | > 0.58 | 11 / 47 | **6 / 30** |
| D3 문자 5-gram 포함률 | 0.54 | 0.32 | > 0.54 | 4 / 47 | **0 / 30** |
| D3 문자 6-gram 포함률 | 0.50 | 0.25 | > 0.50 | 4 / 47 | **0 / 30** |
| D3 문자 8-gram 포함률 | 0.41 | 0.17 | > 0.41 | 4 / 47 | **0 / 30** |
| D5(추가) 최장 공통 연속 부분 문자열 비율 | 0.53 | 0.22 | > 0.53 | 5 / 47 | **0 / 30** |

**D5 는 Validator 가 추가한 규칙이다.** 가설: "진술형은 답변의 한 구간을 **통째로** 가져온다" → 최장 공통 **연속** 부분 문자열이 길 것이다.
`[검증]` **가설이 틀렸다.** 진술형의 중앙값(0.22)이 정상군 중앙값(0.35)보다 **오히려 낮다.** 방향이 반대라 임계값을 어디에 둬도 쓸 수 없다.

#### 두 분포가 겹친다 — 분리 불가의 직접 증거

`[검증]` D3 4-gram 기준, **정상군 상위가 진술형 상위와 같은 구간에 있다.**

```
정상    n4=0.58  lcs=0.41   `general-chatbot-api` 서비스의 엔드포인트 개수가 6 개인지 확인하고 싶습니다.
정상    n4=0.55  lcs=0.53   general-chatbot-api 전체 엔드포인트 목록을 보여주세요.
정상    n4=0.53  lcs=0.50   챗봇 서비스 배포 브랜치는 환경별로 무엇인가요?
정상    n4=0.45  lcs=0.50   general-chatbot-api 의 총 API 개수가 몇 개인지 알려주세요.
──────────────────────────────────────────────────────────────────
진술형  n4=0.23  lcs=0.11   주제 정보 검색 API 의 응답 필드는 `topics` 배열을 포함하며, 각 항목에는 …
진술형  n4=0.20  lcs=0.16   메시지 등록 API 호출 시 필요한 인증 헤더는 `Authorization`이며, …   ← 지어낸 진술
```

- `[검증]` **`"general-chatbot-api 전체 엔드포인트 목록을 보여주세요."` 라는 완벽하게 정상적인 요청이 n4=0.55 인데,
  대표적인 진술형 오염 (2)는 n4=0.23 이다.** 정상 쪽이 2배 이상 높다.
- `[검증]` 원인은 명세가 이미 경고한 그대로다 — **정상 리라이팅은 직전 답변의 대상 이름을 반드시 포함해야 하고
  (`REWRITE_PROMPT` 규칙 1이 그렇게 시키고 있다), 짧을수록 그 이름이 차지하는 비율이 커진다.**
  `"general-chatbot-api"` 19자가 39자 문장의 절반이다. 반대로 긴 진술형은 자기가 새로 만든 표현이 많아 포함률이 떨어진다.
- `[검증]` 새 모델만 보면 거짓 양성 0 을 지키는 임계값에서 n≥5·D5 는 **탐지 0건**이고, n=4 로 낮춰도
  탐지 6건은 **전부 같은 문장 하나**(사례 (1))의 중복이다. 즉 **고유 진술형 8종 중 1종만** 잡는다.
  게다가 그 임계(0.58)는 정상군 최댓값(0.58)과 **여유 0.04** 다. 22건짜리 정상군에서 뽑은 경계라 신뢰 구간이 없다.
- `[검증]` 가장 위험한 사례 (5)(지어낸 진술)는 **점수가 가장 낮은 구간(n4=0.20)** 에 있다.
  **"직전 답변을 베꼈는가" 라는 질문 자체가 이 오염을 포착하지 못한다** — 베끼지 않았기 때문이다.

### B3. 가치 판단 — **기각 권고**

| 기준 | 결과 |
|---|---|
| 진술형 빈도가 낮은가 | **아니다.** 새 모델 가드 통과분의 49.2% (진술형+메타 63.9%). 문제는 실재한다 |

`[추측]` 분리 신호가 있다면 **출처가 아니라 "문장이 요구인가 단언인가"**(종결 형태·화행)일 가능성이 있다.
다만 그것은 agent-21 의 형식 가드 계열이고 **이 티켓의 범위(직전 답변 대조)가 아니다.** 측정하지 않았으므로 권고하지 않는다.
