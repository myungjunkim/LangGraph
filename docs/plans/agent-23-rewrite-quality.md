## 문제

가드가 막아주므로 **안전하지만**, 폐기된 턴은 원문 질문으로 검색한다. 즉 **후속 질문 문맥 보정 혜택을 절반만 받고 있다.**

### 원인 가설 (미검증)

`[추측]` `rewrite` 노드가 `history` 에 **AI 답변 본문을 통째로** 넣는다(`src/agent.py:133-135`).
모델은 "마지막 질문을 다시 써라" 는 지시보다 **"대화를 이어가라" 는 패턴**에 끌리고, 눈앞에 긴 답변이 있으면 그것을 복사한다.
**복사할 재료를 주니까 복사한다** 는 가설이다. 특히 `"넌 안되겠다"` 처럼 리라이팅 대상이 없는 입력에서 두드러진다.

## 왜 바로 고치지 않는가

- **프롬프트 변경의 효과는 예측할 수 없다.** agent-19 M4 에서 확인했다 — 지시를 추가해도 모델이 따른다는 보장이 없다.
- 후보가 여럿이고 **서로 트레이드오프가 있다.** 복사 재료를 줄이면 발동률은 내려가지만 **문맥 보정 품질도 같이 내려갈 수 있다.**
- agent-22 에서 1단계 분리가 값을 했다. 같은 방식으로 **재고 나서 고른다.**

## 1단계 — 실험 (이번 작업)

**`src/` 를 수정하지 않는다.** 후보들은 스크래치패드에서 복제·변형해 측정한다.

### 고정 시나리오 (측정 비교 가능성을 위해 고정한다)

`temperature=0` 이므로 결정론적이다. 각 시나리오는 **2턴**이며, 2번째 턴의 rewrite 를 측정한다.

**정상군 (문맥 보정이 되어야 하는 턴)**

| # | 1턴 | 2턴 |
|---|---|---|
| S1 | 메시지 등록 API 알려줘 | 그거 필수 필드는? |
| S2 | general chatbot api 총 api 개수가 몇 개야? | 그 중에 POST 만 알려줘 |
| S3 | 메시지 등록 API 알려줘 | 방금 알려준 것 중에 필수 파라미터만 다시 정리해줘 |

> S3 은 agent-21 에서 **실제로 오염이 발생한 입력**이다. 반드시 포함한다.

**적대군 (리라이팅 대상이 없는 턴 — 폐기되는 게 정상)**

| # | 1턴 | 2턴 |

| S5 | general chatbot api 총 api 개수가 몇 개야? | 자꾸 틀린 답을하네 |
| S6 | 메시지 등록 API 알려줘 | ? |

### 측정 지표 (두 개를 **함께** 본다)

| 지표 | 정의 | 방향 |
|---|---|---|
| **G. 가드 발동률** | `sanitize_standalone_question` 이 `""` 를 반환한 비율 | 정상군에서 **낮을수록** 좋다. 적대군에서는 **높아도 정상**이다 |
| **Q. 문맥 보정 성공률** | 정상군에서 rewrite 결과가 **대상 이름(API 이름·기능명)을 포함한 한 문장**인가(사람이 판정) | **높을수록** 좋다 |

**G 만 보고 고르지 마라.** 복사 재료를 없애면 G 는 좋아지는데 Q 가 망가질 수 있다 — 그 경우 채택하면 안 된다.
각 후보에 대해 **rewrite 원본 출력 전문**(가드 적용 전)을 기록해라. 숫자만으로는 판단할 수 없다.

### 후보
